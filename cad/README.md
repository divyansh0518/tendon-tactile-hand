# CAD / printed parts

STL files are not stored in this repo. The mechanics are the InMoov i2 hand, so
get the parts from the InMoov STL library:

- https://inmoov.fr/hand-i2/ (links to i2RightHand / i2LeftHand)

## Parts used (i2 hand, one hand)

i2_CoverFingerV3, i2_FingersMoldX5V3, i2_FingersTipX5V2, i2_FingersX5V1,
i2_HandCoverV1, i2_PalmCoverV2, i2_PulleyX5V1, i2_WristGearV1, i2_WristLargeV2


## Print settings i used

Fill in what you actually used (InMoov suggests 0.25 mm max layer height, 30%
infill, 2 mm walls, supports only on the cover / tip parts):

- Printer: Bambu lab h2d
- Material: Pla + and ABS 
- Layer height: 0.16
- Infill / walls: 55% / 4
