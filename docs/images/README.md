# Images

Drop your own photos here. Suggested filenames (the main README links to these):

- `prototype_final.jpg` - the finished hand
- `printing_01.jpg` - parts on the bed / fresh off the printer
- `parts_laid_out.jpg` - all printed parts before assembly
- `assembly_finger.jpg` - a finger being assembled
- `assembly_palm.jpg` - palm / tendon routing
- `tendons_spool.jpg` - servo spools and tendons in the forearm
- `fingertip_sensor.jpg` - hall sensor and magnet in the fingertip
- `wiring.jpg` - electronics
- `demo_grasp.jpg` - grasping something

Real, slightly imperfect photos are better than staged ones.
Compress large images before committing.
